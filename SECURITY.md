# Security policy

## Supported versions

Security fixes are provided for the current `main` branch on a best-effort basis.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or disclose Slack tokens, workspace data, or message content. Use the repository owner's GitHub contact details to report the issue privately. Include reproduction steps, impact, and any relevant version information.

Rotate any Slack token exposed in logs, configuration, an issue, or a pull request immediately.
